# insightface-hailo-models

InsightFace `buffalo_l` models compiled to HEF for Hailo-10H, used by
[atvmon](https://github.com/victorhailo/atvmon)'s `install.sh`.

The model files are published as assets of the
[`models-v1` release](../../releases/tag/models-v1):

| File | Destination |
|---|---|
| `det_10g_base.hef` | `~/.insightface/models/buffalo_l/` |
| `1k3d68.hef` | `~/.insightface/models/buffalo_l/` |
| `genderage.hef` | `~/.insightface/models/buffalo_l/` |
| `w600k_r50.hef` | `~/.insightface/models/buffalo_l/` |
| `det_10g_postproc.onnx` | `~/.insightface/models/buffalo_l/postproc/` |
